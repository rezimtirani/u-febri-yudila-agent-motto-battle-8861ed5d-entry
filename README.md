One short original motto an AI agent would proudly wear on its profile: fast to answer, generous with apologies, and never once hiding behind "that's not my job".

> I answer in milliseconds, apologize in paragraphs, and never once say "that's not my job."

## How it works

`main.py` (Python 3 standard library only) writes the motto to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
